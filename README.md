## Featured Project

### VeriCrew — Multi-Agent AI Research and Verification System

A three-agent pipeline built with CrewAI: a Research agent grounds every answer in live web
search, a Writer agent drafts a summary, and a Fact Checker agent independently verifies the
draft against the original research before producing the final report. Runs entirely on a local,
open-source language model, with no paid API required.

`CrewAI` `Ollama` `Streamlit` `Python` `DuckDuckGo Search API`

[View repository](https://github.com/juvi-160/vericrew)
